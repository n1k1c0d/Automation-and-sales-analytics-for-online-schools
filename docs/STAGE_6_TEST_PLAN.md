# TASK-6.1 · План приёмки демо

Проверки выполняются в отдельном Compose-проекте с пустыми томами, полным FastAPI, Streamlit и набором `synthetic_42`. Даты ручного отчёта — 01.06–31.08.2026, срез 31.10.2026. Для Telegram используются временные Credentials и имитация Bot API. Для Groq — синтетические данные, локальные ответы и зафиксированный результат реальной модели. [Развёртывание](DEPLOYMENT.md), [эталон всех 12 KPI](../tests/integration/test_standard_sales_kpis.py)

| Цепочка | Проверка и критерий успеха | Критерий сбоя |
|---|---|---|
| A. PostgreSQL → FastAPI | `check_db`, миграции, схема `SalesReport`, справочники, сравнение HTTP с SQL и фиксированным эталоном по 12 KPI. | Неверный период, типы, пропущенное поле, HTTP-ошибка или расхождение итогов. |
| B. FastAPI → Streamlit | Readiness интерфейса, реальные карточки в AppTest, фильтр источника, сравнение периодов и выбор менеджера в интеграционных тестах. | Исключение интерфейса, неверные карточки или фильтр не меняет запрос и данные. |
| C. Комментарии → Groq → классификация | Подставные ответы проходят бизнес-валидацию ID, категорий и цитат. Реальные исторические значения точности сверяются с отчётом Stage 4. | Выдуманный ID или цитата приняты, сбой провайдера выдаётся за результат, секрет попал в вывод. |
| D. n8n → FastAPI → KPI → Telegram | Штатные HTTP и Telegram узлы, опубликованный таймер, ручной режим, квитанция и защита от дублей. Результат ручной доставки в реальный чат берётся из Stage 5. | Расхождение с SQL, повторная отправка, отсутствие подтверждения при статусе успеха. |

## Негативные проверки

| Условие | Ожидание |
|---|---|
| PostgreSQL временно отключена на тестовом стенде | `/health` остаётся доступен, чтение KPI возвращает 503, smoke заканчивается кодом 1. После запуска базы связь восстанавливается. |
| FastAPI выключен или адрес недоступен | Smoke отмечает недоступные запросы и продолжает независимые проверки. |
| Некорректный JSON, KPI или даты | Отчёт отклоняется до отправки, диагностика исключает сырое тело ответа. |
| Нет продаж | Сумма и число оплативших равны нулю, неопределённые средний чек и конверсия равны `null`; в Telegram выводится «нет данных». |
| Groq недоступен, возвращает 429 или сообщает об исчерпании квоты | Ограниченные повторы только для разрешённых ошибок, контролируемый код и учёт попыток. |
| n8n не получил отчёт | Журнал содержит причину и конечное число попыток, узел доставки не вызывается. |
| Telegram недоступен или результат неоднозначен | Ограниченные повторы для подтверждённых временных отказов. При неопределённом исходе статус `unknown`, автоматический дубль блокируется. |
| Повтор за тот же период | Для подтверждённого отчёта — `already_sent` с тем же ID и нулём новых попыток. |
| Часовой пояс workflow отличается от Москвы | Проверка экспорта возвращает ошибку. На ускоренной копии опубликованного таймера выполнение должно остановиться до запроса к API. |
