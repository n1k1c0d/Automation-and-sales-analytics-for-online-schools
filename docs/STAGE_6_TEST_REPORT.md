## Регрессия и аудит

- Финальный `uv run --locked python -m pytest --integration -q -ra -W error` в чистом окружении — **259 passed in 45.18s**, включая проверки PostgreSQL, UI, AI и три сценария нового smoke CLI. Ruff lint прошёл, format подтвердил форматирование 89 файлов. На Windows `node --test tests/n8n/telegram_delivery.test.mjs` дал **16 passed**. Оба интеграционных сценария n8n завершились с кодом 0.
- Проверены **34 достижимых Git-коммита, 364 уникальных файла по содержимому и 118 исторических путей**. Поиск форматов токенов Groq и Telegram, а также совпадений с текущими локальными значениями Groq/пароля БД не дал совпадений. Среди исторических путей отсутствуют `.env`, виртуальное окружение, проверенные кэши и логи. В README, документации и `.env.example` не найдены присваивания буквального пароля PostgreSQL или URL с паролем. Это результат проверки указанных признаков в локально доступной истории.
- Генератор создаёт менеджеров вида `Demo Manager 01` и синтетические события. Оба размеченных набора (18 и 24 комментария) прошли проектную проверку потенциальных персональных данных. Для настоящих клиентских данных требуется отдельная подготовка. [Ограничения AI](AI_ANALYSIS.md)
- PostgreSQL и n8n опубликованы на loopback; report-api и обработчик доставки не имеют опубликованных портов. Полный API и Streamlit в проверенном запуске слушали `127.0.0.1`. Публичный доступ к полному API требует авторизации импорта и разграничения прав. [Ограничения развёртывания](API.md#перед-публичным-развёртыванием)

Для ранее доставленного отчёта запуск № 11 вернул `already_sent` с нулём новых попыток. На дату сверки опубликован ежедневный график 09:00 (`Europe/Moscow`).
