## Повтор проверки

Запустите PostgreSQL по README, установите зависимости и примените миграции. Для автономного запуска эталонного теста добавьте к команде pytest путь `tests/integration/test_standard_sales_kpis.py`.

```powershell
uv sync --locked
uv run --locked alembic upgrade head
uv run --locked alembic current
uv run --locked alembic check
uv run --locked python -m pytest --integration -q -ra -W error
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked python -m scripts.generate_synthetic_data --profile data/synthetic/profiles/quality.json
```

Инструкции по PostgreSQL, изолированной проверке отката и запуску сценария приведены в [README](../README.md).
